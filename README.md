# MineWars: Godot Edition 🚀

## 📖 Overview
This repository is a **Godot Engine** recreation of the original [MineWars](https://castle.xyz/d/VeKO4XPU-gEp) game developed on the Castle platform. It is a space combat and exploration simulator where players navigate a fictional solar system, engage in high-stakes dogfights, and mine resources to upgrade their spacecraft.

As you accumulate points through combat and exploration, you can progress through four distinct technological tiers, each offering significant leaps in mobility and destructive capability.

## 🚀 Rocket Tiers & Upgrades

The game features a progression system based on four propulsion and weapon technologies:

| Tier | Engine Type | Weaponry | Characteristics |
| :--- | :--- | :--- | :--- |
| **I** | **Chemical** | Standard Blaster | Default starter; limited range and modest firepower. |
| **II** | **Nuclear** | Enhanced Pulse Gun | Improved fuel efficiency and higher projectile velocity. |
| **III** | **Fusion** | Homing Missiles | High-efficiency engine with self-guiding ordinance. |
| **IV** | **Antimatter** | Antimatter Railgun | Pinnacle tech; one-hit destruction and maximum range. |



## 🎮 Gameplay Features
* **Space Combat:** Battle enemy AI across the star system using various projectile types.
* **Resource Collection:** Mine celestial bodies to earn points required for the next technological tier.
* **Physics-Based Flight:** Utilizes Godot’s physics engine to simulate momentum and thrust in a zero-gravity environment.
* **Solar System Exploration:** Navigate between procedurally placed planets and asteroid belts.

## 🛠️ Tech Stack
* **Game Engine:** Godot Engine 4.x
* **Language:** GDScript
* **Assets:** Custom 2D/3D sprites and particle systems for propulsion effects.

## 💻 How to Run
1. Clone this repository to your local machine.
2. Open the **Godot Project Manager**.
3. Click **Import** and navigate to the `project.godot` file in the root directory.
4. Press **F5** to launch the game.
